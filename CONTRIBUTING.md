# Contributing to Sequence Persistence Evaluation

Thank you for your interest in improving this framework. This project is a research evaluation tool for measuring identity consistency across AI-generated video sequences.

## How to contribute

1. **Open an issue** first if you want to add a feature or change a metric. This helps avoid duplicate work and lets us discuss the design.
2. **Fork the repository**, make your changes, and open a pull request.
3. **Keep changes focused.** One pull request should address one concern.
4. **Add or update tests** if you change the evaluation logic.
5. **Update the README** or notebooks if you change the public API or usage steps.

## Development setup

```bash
git clone https://github.com/byananya/sequence-persistence-evaluation.git
cd sequence-persistence-evaluation
pip install -r requirements.txt
pytest
```

## Sample data

If you add a sample dataset, you must have explicit consent from the person pictured. Do not commit private or unconsented portraits.

## Code style

- Keep dependencies minimal and explain why any new dependency is necessary.
- Add docstrings to public functions.
- Prefer readable code over clever code.

## Questions

Open a discussion or issue if anything is unclear.
